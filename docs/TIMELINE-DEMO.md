# 复杂时间线演示

本地会话名称：**星港回声档案｜复杂时间线演示**，角色为“回声档案员·澄弦”。在 playground 工作区的会话列表中打开它，再选择“时间线”。

演示包含 37 个事件、79 条记忆、50 条直接先后关系和 6 条时间线。其中 2 条记忆尚未关联事件，8 条记忆未记录结束时间。多个记忆共用事件编号，同一事件也可以出现在不同时间轴上。

| 时间线 | 展示内容 |
| --- | --- |
| 宇宙史与毫秒信号同轴（秒） | 从约 46 亿年前到 `0.001–0.003` 秒的信号；使用放大镜直接查看短区间 |
| 远航者七号｜舰载计时（秒） | 出发、巡航、异常、会合与持续开放的对接 |
| 港城现实｜原点2036-06-21 18:00:00（秒） | 风暴与停电、东西两路调查、密钥汇合、档案库开启和疏散 |
| 镜海异世界｜汐刻 | 使用自定义历法的书库、誓约、瞬时倒转与航渡 |
| 回声室｜循环轮次 | 同一破门事件包含三个不连续区间，其他事件记录循环记忆和脱环过程 |
| 单坐标轴｜唯一坐标42 | 所有记录都位于 42，包含瞬时事件和未记录结束时间的承诺 |

## 建议浏览顺序

1. 在事件流程中点击“适配”，查看分支、汇合以及跨世界的连接。放大后可拖动查看局部。
2. 搜索“港区四十五秒停电”，用搜索结果箭头定位；查看详情中的东、西两条后续关系，再追到“双线密钥汇合”。
3. 在宇宙史时间轴点击“三毫秒回声抵达”旁的放大镜，对比全域和局部尺度。时间坐标不变，缩放只改变视窗。
4. 搜索“同一破门事件三次出现”，查看一行中的三个独立标记及三条记忆。
5. 搜索“回声控制台苏醒”，观察未结束区间延伸到港城轴的最新已知坐标 `15600`；该坐标来自未关联事件的潮位抄表记忆。
6. 搜索“四十二号开放承诺”，查看单坐标轴左端的开放标记。没有结束时间不代表已知持续时长。

## 数据构造

可复用数据源是 [`scripts/timeline-demo-data.mjs`](../scripts/timeline-demo-data.mjs)：

```js
import { buildTimelineDemo } from './scripts/timeline-demo-data.mjs'
const { card, document, narrative, summary } = buildTimelineDemo(sessionId, { sourceSeq })
```

该函数只生成角色卡、schema 5 事件文档、演示导览与统计，不创建会话或写入已有数据。`sourceSeq` 可指向演示会话实际的助手消息；本地已创建的演示通过插件事件接口写入并保留了真实来源引用。

各时间轴保留自身原点和数值单位。日期、历法和低位补零属于显示标签；补零不改变坐标，也不表示原文具有对应精度。演示数据不包含旧版本兼容或迁移逻辑。
